# okay-proof — notes for agents

- DOCS: README.md and docs/*.md — every ```scala block compiled and run by `sbt test` (`DocsSuite`, generated by
  build.sbt; a page an object, its blocks one scope). Non-Scala or not-to-run text in ```text blocks.
- Scala 3.3.8, sbt; a cross project `proof` (JVM + Scala.js, sources in `proof/src`, the JVM's own in `proof/.jvm`:
  DifferentialSuite, Bench, ProfileDecision, the docs' suite); depends on okay-scala's PUBLISHED 0.1.1 (resolver in
  build.sbt), not on a working tree. `sbt proofJVM/test proofJS/test` must pass before a commit; commits carry no
  Co-Authored-By lines. Ported from okay-simple 2026-10-25: speed unchanged (decision 7.3 µs before and after).
- Scala.js has no `String.codePoints` nor `BigInteger.TWO`: `Logic.byCodePoints` walks `codePointAt` (CodePointsSuite
  checks it against the arrays' order on 20000 texts).
- In okay-scala an interceptor clause that refines a GADT (`case Infer.Step(...) => pure(thm)`) needs a METHOD with
  its result type (`def veto[X](op: Infer[X], go: X ! Infer): X ! Infer`), called from the polymorphic lambda.
- THE TRUSTED BASE is `Kernel.scala` (`Kernel.derive`, `Arithmetic`), `Logic.scala` and `Linear.scala` (polynomial
  forms, read by `Norm`, `LinComb`, `Tighten`, `MulNonneg`, `Square`); `docs/trust.md` says why
  nothing else is. Any change there: a test of what the rule refuses, not only what it gives (`KernelSuite`). Do not
  add a way to make a `Thm` outside `Kernel` (its constructor is `private[Kernel]`), nor to read one from data other
  than by `Certificate.check` (which derives every step again).
- The effect `Infer`: `Infer.step` accepts an answer only if `t.by eq rule`; `Infer.by` refuses a result of another
  kernel. `EffectsSuite` tries to forge both ways — keep it.
- Scala's precedence goes by an operator's first character: `==>` would bind tighter than `&&`, so implication is the
  word `implies` (it cost a policy read as `… ∧ (last → head)`).
- Speed (`Bench`, `ProfileDecision` for a profiler: `java -XX:StartFlightRecording=… -cp <Test/fullClasspath>
  okay.proof.ProfileDecision 15`): 2026-10-22 a decision 8.3 µs, refused 4.8 µs, from bounds 12.9 µs, ∀-out 263 ns, ∧ 17 ns,
  compute 108 ns, Norm 358 ns; certificates 18 µs written, 26 µs checked. What helped: hashes mixed from the children's cached ones (not
  `caseClassHash`, which walks the product boxed), `union` that makes nothing when a side is empty, sorts checked by
  loops; what did not: free variables computed eagerly (∀-out 315 → 523 ns: reverted, they stay `lazy`).
- LINEAR ARITHMETIC (2026-10-22): `Linarith` (untrusted) finds Farkas multipliers by Fourier–Motzkin, with the
  integers' tightening of the start rows and of derived ones, over the premises sharing atoms with the goal (all for a
  constant goal); it emits `LinComb`, `Compute` of the false constant's negation, `NotE`, `NotI`, `Classic`. An
  equation is two refutations and `Antisym`. `Auto`: a closed computable goal ends its branch (true: `compute`; false:
  no proof); a value a fact gives first; `Linarith` for a comparison next; rules last — that order keeps a decision
  at ~8 µs (with `Linarith` first it was 21 µs).
- LEMMAS: `Lemmas(kernel)`, proved on first use and kept per kernel; `LemmasSuite` checks each closed, of no
  hypothesis, owned. Add a lemma by proving it there (`arith` for linear ones), never as an axiom.
- `given` and `then` are Scala 3 keywords: not parameter names.
- THE INTEGERS AND PRODUCTS (2026-10-22): `Linear` reads polynomials (a monomial one canonical product term, the
  atoms sorted); `MulNonneg`, `Square` in the kernel. `Linarith.falsum` tries, in order: the rationals' elimination
  with tightening; over `Int` the OMEGA TEST (`Omega.scala`: unit/`mod̂` equation elimination with `∃σ` + `ExE`, exact
  elimination, real shadow, then dark/grey by `Infer.cases` + `OrE` — no kernel rule of its own); products of
  premises only if a premise has a real monomial (running them on linear problems made 300 random systems take 300 s
  instead of 0.2 s). Completeness is tested against brute force (`OmegaSuite`: 300 random systems, 300 crossing
  strips — 44 of them by cases, 71 past the rationals' elimination). Pugh's example: ~1000 steps, 1.9 ms.
- Polynomial reading cost linear problems ~25% (a chain 8.1 → 10.2 µs); decisions unchanged (7.4 µs).
- THE SECOND CHECKER (2026-10-22, built): okay-lean's `Okay/Check` + `okay-check`. Certificates carry the theory
  by value and its digest (FNV-1a 64 of the axioms' JSON); decimals written canonically (`Logic.plain`); claimed
  hypotheses checked. Atoms are ordered by `Term.key` (length-prefixed, compared by code points) — NOT toString or
  hashCode — so Lean builds every conclusion alike. ANY change to a rule, to `Linear`'s term building, to `Logic`'s
  substitution or fresh names, to the codec: the same change in okay-lean's `Okay/Check`, then `DifferentialSuite`
  (806 certificates, 0 disagreements on 2026-10-22). Left: prove the Lean rules sound (a semantics: Int as ℤ, Dec as
  ℚ); reach the checker in-process through okay-lean's wire (FFM).
- THE SYNTAX (2026-10-22): `okay.proof.syntax` (`Syntax.scala`, NOT trusted — it only builds data): symbols applied
  like functions (`owns(u, a)`, extension `apply` on `Fn`/`Pred`), a literal taking its place's sort, `+ - *` and
  `< <= > >= === =/=` by sort; a wrong sort throws at once. `SyntaxSuite` checks it builds `Bank.policy` exactly.
  Docs examples use it; in a tuple `val (User, Account) = …` capitals are patterns — declare sorts one per line.
- THE POLICY LANGUAGE (2026-10-25): module `policy` (package `okay.policy`, JVM + Scala.js), specs/policy.md.
  Parser (Lexer + recursive descent, places), Printer (round trip), Types (checker; conditions to negation normal
  form), Theorize (the policy as a `Theory`: a rule `∀ caller, args. C ⇒ allow:tool(...)`), Eval (untrusted: chooses),
  Prove (builds the proof from the evaluation, no search: axiom, ∀ out, atoms by `Compute` with the facts' values then
  `Subst` back with each fact's equation reversed), Decide (deny > allow with a condition > ask > default deny, fail
  closed), Facts / Store effects (Store.Memory with windows), Tests (a policy's `test` blocks). An allow with no
  condition allows every call; `count` (decides nothing) makes its updates for calls that go ahead. Text tests
  `starts`/`ends`/`contains` are the kernel's `take`/`takeRight`/`indexOf` (added 2026-10-25, by code points — and in
  okay-lean's Check/Arith.lean, commit 55f4bf1; DifferentialSuite has their certificates: 856, all agreed). Decision
  8.4 µs JVM; certificate 53 µs.
